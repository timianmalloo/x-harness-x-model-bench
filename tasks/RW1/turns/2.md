Add a function `format_money(amount, currency)` to `humanfriendly/__init__.py`. `currency` is a three-letter code:

- `'USD'` gives `'$1,234.50'` for `1234.5`.
- `'EUR'` gives `'1.234,50 €'` for `1234.5`, and `'-1.234,50 €'` for `-1234.5`.
- `'JPY'` gives `'¥1,235'` for `1234.5`: no decimals, rounded half up.

Any other code raises `ValueError`.

`format_dollars(amount)` must now return `format_money(amount, 'USD')`, and it must get that result by calling `format_money`.

Add tests for the new function to `humanfriendly/tests.py`, and keep the existing tests passing.
