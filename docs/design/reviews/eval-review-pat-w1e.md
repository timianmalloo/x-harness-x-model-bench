# RV-PAT review: W1-E `docs/design/eval-discriminate.md`

Read in full on `design/eval-discriminate` (549f7bc4, 456 lines). Compared with `main` at fd77ae2a: `eval-seam-contracts.md` §2, §6, §8, §9, §11 (rev 5), R-98 in `docs/notes/rulings.md`, `eval-property-grader.md` (merged W1-F rev 3, lines 125, 155, 200, 214, 348), and the code: `engine.py:69-85,92,604-651`, `profiles.py:38-41,106-108`, `config.py:34,102-120`, `cli.py:98`, `plan.py:240-245,288,336-345`. RV-TA's findings (`eval-review-ta-w1e.md`) are not repeated except where I confirm or refute its seam claims (finding 4) or add a pattern fix (findings 2, 3).

**Conforms.**
- `SyntheticLauncher` is a Strategy behind the existing `Launcher` port, injected through `engine.Config.launchers: dict[str, Launcher]` (`engine.py:92`, `:604`); the agent is a Test Double of the real ACP boundary, not a mock of the engine. The Protocol members match `engine.py:69-85`. Spike S-E1 backs the "no `engine.py` edit" claim. Verified.
- The overlay rule (§6) matches W0 §2 rev 5 point for point: engine-built copy, same relative paths, no deletion, the same refusal list and limits, multi-turn not built in E1. Copying inside the cell is the right place (ORCL-A).
- "Specification predicates returning `Failure`" (a Notification, all items reported at once), `ast.literal_eval` for `variants.py`, and importing `runner.applicable` and `property.at_scale` instead of copying them are the right reuse rungs.
- Readiness codes 002, 003, 004, 005, 006, 007, 008, 009, 010, 011 map to W0 §11 rows as worded. Code 001 also covers "record exists but lacks the real-host probe", which W0 §2 rev 5 and §6 endorse ("fails HB-RDY-001").
