### Ruling (CR46-0): option (a), `resume.py` is a sanctioned ninth archive reader

1. **Why (a).** W1-K requires the resume to read the archive tree itself: the folder check (step 3(c)), the two-level sweep (step 6) and the snapshot redo (3.4). The redo needs `archive.snapshot_folder`, which is a guard token by construction, exactly as for `grade/runner.py` (row 11). So no refactor can leave `resume.py` with zero tokens while it does what W1-K asks.
2. **Why not (b).** Moving `:97` and `:107` behind an `archive.py` helper still leaves `snapshot_folder` at `:301`, so `READERS` could not stay eight. Removing that token too would mean either dropping a W1-K step or narrowing the guard's token set, which weakens the control. Neither is a code change I may assign.
3. **Why not (c).** W1-J's guarantee is that every archive reader is listed and none mistakes a `turn-<n>` folder for an attempt. `resume.py` keeps it. At `:97` the snapshot name comes from the row (`archive.snapshot_of`). At `:301` it comes from the helper. `:107` lists only cell folders and sweeps temps at both levels, as W0 section 4 asks. No line in `resume.py` globs over `archive/<cid>`. The guarantee does not change; only the inventory grows by one row. That is an erratum, not a decision for the Owner.
4. **The erratum (mine, applied in this commit):** `docs/design/eval-multi-turn.md` gains a dated erratum line (`:35`), a ninth row in the section 7 sweep table (`:426`), and "9 with `resume.py`" in the T-SWEEP-1 row (`:544`). The RV-TA 8 row (`:639`) stays as the review's historical record.
5. **What the Leader edits at the join** (`tests/test_archive_readers.py`, one hunk, before the recount is re-run):
   - `:7-8`: add `"resume.py"` to `READERS`.
   - `:50`: change `assert len(READERS) == 8` to `assert len(READERS) == 9`.
   - Nothing else. `ANNOTATION`, `GIT_ARCHIVE` and the token set stay as they are. Expected result: both T-SWEEP-1 tests pass (the scratch check above shows the set equal at 9).
6. **Not assigned, recorded as an observation:** `:97` spells the attempt folder name (`attempt-{n}`) a fourth time, after `engine.py`, `views.py` and `grade/runner.py`. An `archive.attempt_folder` helper would be the single definition. No design asks for it, and nothing fails without it. It is a next step, not a condition of this join.
7. **A latent trip, recorded:** the guard's `broad_archive_globs` returns true for `resume.py` (the `"archive"` constant plus `rglob("*")` at `:195`, Verified). No test applies it to the real tree; it runs only on the synthetic fixture. The glob at `:195` lists files inside one published `turn-<k>` folder, never sibling folders. If a later change applies that check to `src/`, `resume.py` will need a named exception.
8. **What reverses this ruling:** a reader in `resume.py` that finds `turn-<n>` or `attempt-<n>` folders by glob, not by row or helper; or the Owner narrowing what the resume may touch. Either sends it back to me, and (c) becomes a decision request.
