Benchmark instrumentation for drift, tool use and the Codex/Copilot contradiction

Goal. Before the next comparison run, the bench measures, for every harness, the facts that decide whether a model drifts or over-works more in one harness than another, at both layers (the headless cells and your interactive sessions). The known confounds are removed or measured.

Done when. Every row below is merged to main with its tests red-then-green. The full suite, the stamped tier and the gate ring pass. The behaviour page, run on the existing six runs, shows the new columns, or "not recorded" with the reason where an old run cannot supply them.

Not in scope. The re-run itself (you run it after this lands). The four decisions (B10 Copilot path checks, B12 Codex personal skills, B15 the pack track in the ai-forward repo, B16 agy schedule). Pack changes in the ai-forward repo.

How it runs. Seven tracks in parallel, each in its own worktree and branch, then one integration branch, the gates, and a merge to main.
