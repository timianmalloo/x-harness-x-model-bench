Ranking and insights

  1. Claude Code / Opus 5.5 leads on correctness (pass@1 0.82, pass^3 0.71) and every quality area, but is the most expensive per pass at $4.10 and Pareto-dominated on tokens per solved task. runs 0142–0189
  2. Codex / GPT-6 Sol is the efficiency leader: 61% of Opus's tokens per solved task with a 6-point pass@1 gap; its interval overlaps Sonnet 5's on pass^3, so ranks 2 and 3 are not separable. runs 0001–0048, 0190–0237
  3. Same model, different harness: GPT-6 Sol in Copilot CLI trails Codex by 9 points pass@1 and uses 1.8× the tokens per solved task, with the gap concentrated in scenario 4 and 6 tasks. Cache hit ratio (44% vs 79%) explains most of the token difference. runs 0049–0096 vs 0001–0048
  4. Drift is the widest spread of any area (54–84). Both GPT-6 combos lose adherence after the first compaction; Claude Code combos re-read the spec after compaction 71% of the time. drift.py re-read rate; runs tagged compaction=true
  5. Variance warning: F-tasks (multi-agent) have the largest per-rep spread for every combo; three repetitions are not enough there. Recommend 5. pass^3 vs pass@1 gap on F1–F3

With and without the ai-forward pack

  • Pack on moves drift & adherence (+14 to +17), rigor (+11 to +12), specification (+13 to +14) and coordination (+17 to +26) for every combo; correctness moves +3 to +4, inside the interval for two combos. pack-effect panel
  • Pack on costs 8–12% more tokens per run, almost all cache-write tokens from the larger repo context on turn 1; cache hit ratio is higher with the pack on for all combos, so the net cost-of-pass delta is −$0.20 to +$0.35. cost.py cache_write_amplification
ai-forward: split TESTING.md so the mutation directive is a 12-line file loaded on every turn; the full KB is only read on 23% of runs and costs 6.1K tokens when it is. runs 0142–0189 tool log
ai-forward: the intent log lost 18% of actions on Codex because the writer expects a shell hook Codex does not fire; add a post-edit fallback in the coordination protocol. coordination.py orphan_actions, Codex runs
Codex-specific: an AGENTS.md variant that front-loads the layering rules; Codex reads AGENTS.md once and never re-reads, so the rules must fit its first-turn budget. re-read rate 0.04 on Codex vs 0.71 Claude Code
Claude Code-specific: a PostCompact hook that re-injects the task spec; drift slope halves in the two runs where this was simulated. runs 0177, 0181
Copilot-specific: a custom agent with an explicit build-then-test step; Copilot declared done without running tests on 31% of D-tasks. rigor.py verification_before_done
