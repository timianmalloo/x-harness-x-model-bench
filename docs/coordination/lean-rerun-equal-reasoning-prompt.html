Why this run exists. The 2026-10-10 lean run compared harnesses at their default settings: Codex ran gpt-6.1-sol at reasoning effort low, Copilot ran the same model at medium, and Claude Code at its own default. The cost comparison (docs/coordination/harness-cost-comparison.html) therefore mixed harness behaviour with reasoning setting. It also found that reasoning text is barely recorded (Claude Code: 202 thinking blocks, 1,793 characters in total; Codex: encrypted reasoning, summaries off by default; Copilot: readable text on 77 of 214 messages), and that none of it reaches the bench's records.
