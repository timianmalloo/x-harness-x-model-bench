Tracks

Why pay the multiplier. An orchestrator-worker shape costs roughly 15× the tokens of one session (GO6). Each track's justification is named in the detail table: independence, isolation, context hygiene, or machine time. The token figure in each budget is a context ceiling per dispatch (the CEIL-A split threshold: the floor measured at the first edit plus the planned work), not total spend; spend is measured at each hand-back and summed in the run report. Last run's floors: Opus Coordinator 137k, Opus worker about 109k, Haiku about 99k, Grok about 117k, Agy about 166k, all for ~75 kB briefs.

Routing. Opus carries every T2 track and every track whose failure mode is judgement, including the validity gate. Grok and Agy take bounded, test-heavy work with a brief under ~30 kB. Floor canary: the first Grok track (R-READ-CODEX) and the first Agy track (R-READ-COPILOT) are dispatched alone first; their floors at the first edit are recorded, and every later Grok or Agy row is routed by that number (a floor that leaves under 60k of room routes the row to Opus). Haiku takes mechanical work. Codex, Sonnet and Copilot are not workers.

Stop rules

From the prompt, plus the plan's own:

  • the health check trips twice → stop and report;
  • the host becomes unstable (LOAD-A, JOB-A shapes) → record the evidence first, then stop;
  • main cannot be made green within one bisect round → stop;
  • a probe (S3 or S5) shows a served setting that differs from its pin → stop;
  • an operator-only blocker gates every remaining track → stop and report;
  • a torn row or a classifier denial → that action stops and goes to the operator (never edit a log);
  • two consecutive authentication failures for one harness in a batch → the batch stops (ADR-0025 §7).
